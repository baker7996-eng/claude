# FPL Draft Assistant

Weekly analysis for an FPL Draft league: gameweek review, free agents ranked by
form and fixtures, and transfer/trade suggestions.

## Run locally

```bash
npm install
cp .env.example .env.local   # optional: set your FPL_ENTRY_ID
npm run dev
```

Open http://localhost:3000.

Your team id is the number after `/entry/` in the URL of your Points page on
draft.premierleague.com.
